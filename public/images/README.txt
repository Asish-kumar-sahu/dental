🏥 CLINIC PHOTO STANDARDS (trust build karne ke liye):
═══════════════════════════════════════════════════════════════════

🌊 HERO IMAGE:
   ✓ Natural bright lighting (NOT moody)
   ✓ Clean white/aqua color tones
   ✓ Professional, not "spa-like"
   ✓ Subjects: doctor-patient interaction, modern equipment,
     happy confident patient
   ✗ Avoid: dark dramatic shots, stock photo look

👨‍⚕️ DOCTOR PHOTOS:
   ✓ White coat / professional attire
   ✓ Clean studio ya clinic backdrop
   ✓ Warm genuine smile
   ✓ Eye contact with camera
   ✓ Consistent lighting across all doctors
   ✗ Avoid: casual clothes, harsh shadows, group photos

💉 TREATMENT IMAGES:
   ✓ Close-up of treatment in action
   ✓ Clean sterile environment visible
   ✓ Modern equipment/technology shown
   ✗ Avoid: scary/medical-drama shots, blood, needles closeup

📸 BEFORE/AFTER (MOST IMPORTANT):
   ✓ EXACT same angle (use tripod!)
   ✓ EXACT same lighting
   ✓ EXACT same distance
   ✓ Same time of day preferably
   ✓ WRITTEN patient consent ZAROORI
   ✓ Real patients (NO stock photos)
   ✗ Avoid: different filters/retouching between before/after

💬 PATIENT (TESTIMONIAL) PHOTOS:
   ✓ Natural warm smile
   ✓ Taken at clinic for authenticity
   ✓ Square crop, center face
   ✓ Good lighting on face


═══════════════════════════════════════════════════════════════════
⚠️  PATIENT CONSENT (VERY IMPORTANT):
═══════════════════════════════════════════════════════════════════

Medical/aesthetic clinics mein patient photos use karne se pehle:

1. WRITTEN consent le lo (email/paper signed form)
2. Consent specific ho: "website pe use karne ke liye"
3. Before/after use karne ke liye alag consent
4. Testimonials ke liye patient ka naam use karne se pehle bhi consent

Ye legal requirement hai — bina consent ke photos use karna
HIPAA/data protection violations create karta hai.

🔄 KAISE REPLACE KARNA HAI:
═══════════════════════════════════════════════════════════════════

Simple method:
  1. Apni image ko wahi EXACT naam do
  2. Purani delete karo, apni paste karo
  3. DONE!

Example:
  Hero image replace karna hai?
  → Apni image ka naam "hero-clinic.jpg" rakho
  → public/images/hero/ me paste karo
  → Website automatic update
